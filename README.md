# Veltrix Operations Optimization Platform

A web platform that turns orders, resources, costs and constraints into production, delivery and inventory plans that people can review, approve and execute. Decision engines use operations research and mathematical optimization.

This repository is built by a team where **Claude Code** (lead engineer) and **Codex** (implementation engineer and independent checker) write most of the code, and humans own scope, model correctness and acceptance.

## Start here

1. Read `docs/FILE_GUIDE.md`. It explains every file in this repository, what it is for, who maintains it and which AI model to use with it.
2. Complete the pre-development checklist in `docs/FILE_GUIDE.md` (section "Before day one").
3. Begin with task `docs/tasks/P0-01.md`.
