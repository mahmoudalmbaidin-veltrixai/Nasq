TASK P9-03: Reports and exports
PRD: §21   Requirements: EXE01, FIN01   Depends on: P6-03, P9-02, P2-07

CONTEXT
§21: core reports are the detailed plan, exceptions, two-scenario comparison, planned versus actual, approved financial impact and change and approval history; Excel and PDF export; reports include scope, date, version, currency and units.

BUILD
1. Six report generators listed in §21.
2. XLSX and PDF outputs with a standard header block.
3. Arabic PDF rendering with an embedded Arabic font and RTL layout; English layout.
4. Authorization recheck at download and formula-safe cells.

NON-NEGOTIABLES
- Reports never mix projected and actual values without labels.
- Organization scope comes from the session or API key only; permissions are enforced on the server; every mutating action writes an audit event.
- No secrets or personal data in code, fixtures, logs or messages. User-facing text exists in Arabic and English.

ACCEPTANCE (automated tests; name requirement tests test_<REQ-ID>_<behaviour>)
- Snapshot tests for each report in both languages.
- A revoked user cannot download a saved link.
- Header fields present in every report.

OUT OF SCOPE
Scheduling of reports by email (later).
