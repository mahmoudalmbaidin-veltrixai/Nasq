TASK P1-02: Authentication, invitations and sessions
PRD: §6, §24   Requirements: IAM01   Depends on: P1-01, P0-03

CONTEXT
§24 asks for trusted authentication, additional verification for sensitive accounts, sign-in throttling and session revocation. §6: personal accounts must not share a password. Implement according to ADR-003.

BUILD
1. Invitation flow with a single-use, expiring token sent by email.
2. Sign in, sign out, sign out of all sessions; password hashing with argon2id (or OIDC if ADR-003 chose it).
3. TOTP multi-factor authentication with recovery codes, enforced for org admin, approver, finance and platform admin roles.
4. Throttling per account and per IP with exponential backoff and temporary lockout.
5. Session list for the user and for org admins, with revoke.
6. Password reset with expiring token; audit events for every authentication action.

NON-NEGOTIABLES
- Tokens and recovery codes are stored hashed.
- Messages never reveal whether an account exists.
- Cookies are HttpOnly, Secure, SameSite=Lax; CSRF protection on state-changing requests.
- Organization scope comes from the session or API key only; permissions are enforced on the server; every mutating action writes an audit event.
- No secrets or personal data in code, fixtures, logs or messages. User-facing text exists in Arabic and English.

ACCEPTANCE (automated tests; name requirement tests test_<REQ-ID>_<behaviour>)
- Expired or reused invitation fails.
- A sensitive role cannot complete sign-in without MFA.
- Ten failed attempts trigger throttling.
- A revoked session is rejected on the next request.
- Each case has a test.

OUT OF SCOPE
Role and site permissions (P1-03).

HANDOFF
Work on branch feat/p1-02-authentication-invitations-and-sessions. Run make lint, make typecheck and make test. Open a PR whose description contains: summary, design decisions, a traceability table (task, PRD section, requirement id, test name), commands run with results, known limitations, and questions for the reviewer. Do not report the task as done if any acceptance test is missing, skipped or failing.
