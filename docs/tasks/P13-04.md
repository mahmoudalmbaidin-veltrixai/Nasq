TASK P13-04: Route independent validator
PRD: §13, §27   Requirements: LOG01   Depends on: P13-01, P4-03

CONTEXT
§13 core acceptance: independent recomputation of capacities and travel, service and break times at every route stage, with no silently dropped orders; plans using future traffic data unavailable at decision time are not fair comparisons.

BUILD
1. Per-stage recomputation of onboard load against weight and volume capacity.
2. Per-stage recomputation of travel, service, waiting and break times against windows and working hours.
3. Compatibility checks and completeness (every order served or listed as unserved).
4. A check that travel times come from the matrix snapshot available at decision time.

NON-NEGOTIABLES
- No import from packages/engines.
- Organization scope comes from the session or API key only; permissions are enforced on the server; every mutating action writes an audit event.
- No secrets or personal data in code, fixtures, logs or messages. User-facing text exists in Arabic and English.
