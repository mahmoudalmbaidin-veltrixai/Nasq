```text
TASK P2-03: Units, currencies and time module
PRD: §9, §20   Requirements: DAT03   Depends on: P2-01

CONTEXT
DAT03: item and case differences are detected or converted explicitly. §9: no aggregation across currencies without documented conversion; store time consistently and display in the site's time zone, keeping local workday meaning for shifts; never use a fixed UTC offset.

BUILD
1. A unit registry per product (base unit, conversions with factor and rounding rule) and a Quantity type that carries its unit.
2. convert(quantity, to_unit) that raises when no conversion path exists.
3. A Money type and an FX rate table with source and effective date; conversion requires an explicit rate.
4. Time helpers using zoneinfo: site-local workday, shifts that cross midnight, daylight-saving transitions.
5. Lint rule or test that forbids fixed-offset timezone construction in product code.

NON-NEGOTIABLES
- No implicit conversions.
- No float for money.
- Organization scope comes from the session or API key only; permissions are enforced on the server; every mutating action writes an audit event.
- No secrets or personal data in code, fixtures, logs or messages. User-facing text exists in Arabic and English.

ACCEPTANCE (automated tests; name requirement tests test_<REQ-ID>_<behaviour>)
- Property tests for conversion round trips.
- Adding items to cases without conversion raises (test_DAT03_*).
- A shift crossing a DST change computes the correct duration in Europe/Berlin; Asia/Amman workday test passes.
- Summing amounts in two currencies without a rate raises.

OUT OF SCOPE
Engine time discretization (P5-02).

HANDOFF
Work on branch feat/p2-03-units-currencies-and-time-module. Run make lint, make typecheck and make test. Open a PR whose description contains: summary, design decisions, a traceability table (task, PRD section, requirement id, test name), commands run with results, known limitations, and questions for the reviewer. Do not report the task as done if any acceptance test is missing, skipped or failing.
```
