PRD: §7, §27, §31   Requirements: KPI01   Depends on: P2-04, P6-03, P9-01

§7: a short assessment, a data sample and fit evaluation, configuration, small tests, comparison with a baseline plan, then a parallel run before operational adoption; transition depends on data quality, plan acceptance, security and agreed performance.

BUILD
1. A fit assessment questionnaire stored per prospect (process, resources, systems, financial pain).
2. A data sample profiler: completeness, units, duplicates, plausibility, with a readiness score and reasons.
3. Baseline plan import (the planner's current plan) and comparison on the same scope.
4. A parallel-run report: planned versus baseline versus actual, with change requests classified as configuration, reusable development or separate customization (§7).
