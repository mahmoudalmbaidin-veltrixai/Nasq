TASK P9-01: KPI registry and measurement
PRD: §20   Requirements: KPI01   Depends on: P5-06, P7-03

CONTEXT
KPI01: units, denominators and commitment-date definitions are documented. §20: every indicator has a definition, formula, unit, period, source and owner; separate projected and actual; define on-time delivery by order, line or quantity and against the original or revised commitment.

BUILD
1. A KPI definitions table and API: definition, formula, unit, period, source, owner.
2. Production KPIs: lateness, on-time delivery, changeover hours, overtime, utilization.
3. Separate projected (from plan) and actual (from events) series with data freshness.
4. Configurable on-time definition (order, line or quantity; original or revised commitment) stored with each measurement.
5. Baseline import for before-and-after comparison.

- No KPI is shown without its definition and freshness.
- Organization scope comes from the session or API key only; permissions are enforced on the server; every mutating action writes an audit event.

- Projected and actual values are stored separately.
