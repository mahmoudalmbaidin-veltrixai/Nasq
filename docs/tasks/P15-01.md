```text
TASK P15-01: Explanation assistant (deferred extension)
PRD: §19, §29, §32   Requirements: AI01   Depends on: P8-01, customer demand

CONTEXT
§19: an optional language assistant may express verified information but must not invent causes or financial values. AI01: separate testing and approval for any constraint change. §32 defers chat and multi-agent assistants until need is proven.

BUILD
1. A read-only assistant that receives only typed explanation records and validated numbers as context.
2. Answers cite the explanation ids they use; refuses when no verified record exists.
3. Any suggested constraint change becomes a draft scenario that needs approval.
4. A separate evaluation set testing for invented causes, invented numbers and cross-tenant leakage.
5. No customer data used for training a shared model (§24).

NON-NEGOTIABLES
- Disabled by default and enabled per organization.
- Organization scope comes from the session or API key only; permissions are enforced on the server; every mutating action writes an audit event.
- No secrets or personal data in code, fixtures, logs or messages. User-facing text exists in Arabic and English.

ACCEPTANCE (automated tests; name requirement tests test_<REQ-ID>_<behaviour>)
- Evaluation set shows zero invented numbers on the test set (test_AI01_*).
- Cross-tenant prompt tests pass.

OUT OF SCOPE
Forecasting models (separate project when validated).

HANDOFF
Work on branch feat/p15-01-explanation-assistant-deferred-extension. Run make lint, make typecheck and make test. Open a PR whose description contains: summary, design decisions, a traceability table (task, PRD section, requirement id, test name), commands run with results, known limitations, and questions for the reviewer. Do not report the task as done if any acceptance test is missing, skipped or failing.
```
