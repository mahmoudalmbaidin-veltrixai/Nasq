```text
TASK P5-03: Production independent validator
PRD: §12, §27   Requirements: PRD01, RUN03   Depends on: P5-01, P4-03

CONTEXT
§27 requires an independent validator for schedules, capacities, times and materials. Build it from docs/engines/production/formulation.md and the data dictionary. Do not open or import packages/engines.

BUILD
1. Rules: line compatibility; no overlap including setup; precedence with transfer time; changeover times applied for the actual sequence; working calendar and downtime; time-phased material balance (no consumption before receipt and release); batch size limits; locks and frozen window respected.
2. Independent recomputation of lateness per order.
3. A completeness rule: every order is either scheduled or listed as unscheduled with a reason; nothing is dropped.
4. Mutation test helpers that inject each violation type into a valid plan.

NON-NEGOTIABLES
- No import from packages/engines.
- Measured values and limits must be reported in each violation.
- Organization scope comes from the session or API key only; permissions are enforced on the server; every mutating action writes an audit event.
- No secrets or personal data in code, fixtures, logs or messages. User-facing text exists in Arabic and English.

ACCEPTANCE (automated tests; name requirement tests test_<REQ-ID>_<behaviour>)
- Every injected violation type is detected.
- Zero false positives on all enumerator-optimal plans.
- Completeness rule catches a silently dropped order.

OUT OF SCOPE
UI display of violations (P10-05).

HANDOFF
Work on branch feat/p5-03-production-independent-validator. Run make lint, make typecheck and make test. Open a PR whose description contains: summary, design decisions, a traceability table (task, PRD section, requirement id, test name), commands run with results, known limitations, and questions for the reviewer. Do not report the task as done if any acceptance test is missing, skipped or failing.
```
