Start here: everything to have ready before development

The kit holds every document the team and the two AI agents need before anyone writes code. This guide explains each file: what it is for, who works on it, which AI model to use with it, when it is needed, and what you must do.

Before day one

Ten things to do, in order, before you start task P0-01. Ticks are not saved when you close the page.

    Which model for what

    Each task file names its model. These are the rules behind those choices.

    Claude Code

    Lead engineer: architecture, engines, the hard parts
    Claude Opus 5.5 (deep)Architecture, tenancy, permissions, plan lifecycle, approval, outbox, every engine formulation and engine, diagnosis, finance, security, release audit.
    Claude Sonnet 5.5 (standard)Repository scaffold, data model from the approved dictionary, frontend foundation, Gantt screen, deployment, acceptance pack.
    Claude Haiku 5.5 (quick)Small documentation edits and status updates only.
    Claude Fable 5.2 (optional)If your plan includes it: the hardest reasoning, such as engine formulations and the threat model.

    Codex

    Implementation engineer and independent checker
    Top coding model, highest reasoning (deep)All validators, test and benchmark suites, the reference-case enumerator, authentication, units and time, and reviews of Claude Code's deep work.
    Top coding model, medium reasoning (standard)APIs, import rules, reports, alerts, screens, CI, monitoring, backups, support tools.
    Codex model names change often, so this kit does not name one. Choose the current top coding model in Codex settings.

    People

    Decisions that are never delegated to AI (PRD §29)
    Product ownerScope, data dictionary, coverage register, release gate.
    OR specialistSigns every engine formulation and engine PR; sets regression thresholds.
    Tech leadMerges PRs, owns security review and the decisions log.
    Customer ownersOperational acceptance and benefit attribution.
    Three rules: the reviewer always uses at least the same tier as the author; engine work and its review are always deep tier; if a standard-tier session keeps failing, restart the task on deep tier. Model names and availability depend on your plans, so check them before you start (Claude Code docs: docs.claude.com/en/docs/claude-code/overview).
